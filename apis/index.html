개발자 Token 발급 받기

API 사용을 위해 AQR 개발자 Token을 발급 받으세요.

AQR API는 AQR 개발자 Token을 파라미터로 입력해야 사용할 수 있습니다.

AQR 서비스의 "Advanced" 등급 또는 제휴사에 한해서 개발자 Token을 제공합니다.
개발자 Token은 아래의 AQR Square(페이지 관리 사이트)에 가입 및 로그인 후 화면의 우측 상단 "개인정보수정" 메뉴에서 확인 할 수 있습니다.

공통 사항

모든 API 는 같은 주소로 POST 요청을 보내고, 본문의 action 값으로 기능을 고릅니다.

API 를 호출하는 서버의 IP 가 AQR 에 등록되어 있어야 합니다. 등록되지 않은 IP 에서 호출하면 403 으로 거절합니다.
개발자 Token 이 드러나지 않도록 브라우저가 아닌 서버에서 호출하세요.

요청
항목 설명 타입
POST https://aplx.link/api/ 모든 API 의 주소입니다. -
AQR-DEVELOPER-TOKEN 헤더 — 부여받은 개발자 Token String
action 본문 — 기능 이름 (create / delete / list / detail / update / update_qr_style / create_bulk / delete_bulk / slot_count / stats) String
email_address 본문 — 가입시 입력한 이메일 주소. Token 과 함께 회원을 확인합니다. String

본문은 application/x-www-form-urlencoded 로 보냅니다. 파일을 함께 보낼 때(QR 스타일 업데이트)만 multipart/form-data 를 씁니다.

응답

응답은 JSON 이며, 처리 결과에 맞는 HTTP 상태 코드(Errors)를 함께 보냅니다.

파라미터명 설명 타입
result 처리 결과 ("success" 또는 "error") String
message 처리 결과가 "error"일 경우 오류 내용 String
sendstatus 결과 코드 (0 = 성공, 음수 = 실패) Integer
data 기능별 결과 데이터 (없는 기능도 있습니다) Object
페이지 ID (uniq_keyword)

페이지(계좌 정보)는 생성할 때 받은 uniq_keyword 로 가리킵니다. 목록 · 상세 응답에도 들어 있습니다. 내 페이지가 아니거나 없는 uniq_keyword 를 보내면 404 로 답합니다.

통계

페이지 사용 통계 가져오기

내 모든 페이지를 합친 사용 통계를 가져옵니다. AQR Square 의 "페이지 사용 통계" 화면과 같은 값입니다. 전체 기간의 조회 구간별 페이지 수와, 주(일요일~토요일)마다의 조회수 · 좋아요 수를 돌려줍니다.

집계 기준
· 조회수는 QR 코드 주소(short_url)로 들어온 조회만 셉니다. 휴대폰(iOS · Android)이 아닌 기기에서 연 경우는 빼고 셉니다.
· 주는 일요일 0시(한국 시각)에 시작하는 7일입니다. 가장 먼저 만든 페이지의 주부터 이번 주까지 한 주에 한 항목씩 들어 있습니다.
· 삭제한 페이지는 집계에 넣지 않습니다.
